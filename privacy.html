Privacy Policy

Last updated: 2026-10-21

Who uses this application

Personal Workspace Assistant is used only by its owner. It is not available to the public.

What data it accesses

With the owner's consent, the application accesses the owner's own Google account data through Google APIs (Gmail, Drive, Calendar, Docs, Sheets, Slides, Forms, Tasks, Contacts and Apps Script) only to carry out requests the owner makes.

How data is stored and shared

  • Access tokens are stored only on the owner's own computer.
  • The application does not sell, rent, or share Google user data with third parties, and does not use it for advertising.
  • The application does not collect data about any other person.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.
